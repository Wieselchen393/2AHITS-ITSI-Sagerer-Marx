- metasploitable: 192.168.1.51
- Host: 192.168.1.50
- St. Gateway: 192.168.1.50

- kali: 192.168.40.142

#### Unterschied
- Bridge: Nutzt Ethernet 2 des Host (keine Verbindung nach außen möglich)

### Datenübertragung Meta -> Kali (Web server)
#### Webserver: apache2
```
$ ps ax
```
- Apache2 Webserver lauft
```
$ sudo netstat -tlpn | grep apache
```
- Apache2 nutzt Port 80

- Standart Verzeichniss: /var/www/test/
- Datei Anlegen
```
echo Hallo | sudo tee Hallo.txt
```

- Datei in Kali herunterladen
```
curl 192.168.40.147/test/Hallo.txt > Hallo.txt

```

### Datenübertragung Kali -> Meta
#### Python Web-Server
```
$ python3 -m http.server 8000
```
- Befehl im zu teilenden Verzeichniss ausführen

```
curl 192.168.40.142:8000/Test.txt > Test.txt
```
